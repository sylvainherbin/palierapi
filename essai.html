Demander un essai gratuit

Répondez au mail reçu ou écrivez à sylvainherbin2b@gmail.com. Indiquez que vous souhaitez tester PalierAPI. Vous pouvez arrêter à tout moment en répondant STOP.

Les questions pour préparer votre bref

  1. Quel est le nom de votre agence et à qui adresser les deux brefs ?
  2. Quelle version API utilisez-vous, s'il y a des appels API ? Exemple : 2026-07. Si vous ne savez pas, dites-le.
  3. Maintenez-vous une application publique, une application personnalisée ou aucune application ?
  4. La vitrine utilise-t-elle un thème Shopify ou une vitrine séparée, par exemple Hydrogen ?
  5. Quelles API ou surfaces maintenez-vous : Admin GraphQL, Storefront, comptes clients, webhooks, thèmes/Liquid, POS, Functions ou extensions de checkout ?
  6. Quelles ressources ou opérations sont concernées ? Pour les webhooks : sujets et mode classique ou Events. Pour les thèmes : utilisez-vous Shopify CLI et des métachamps ?
  7. Quel périmètre faut-il suivre ? Une description suffit au départ ; ne donnez un domaine public de boutique que si vous êtes autorisé à le partager.

Ne devinez pas les réponses. Nous clarifierons les inconnues avec votre responsable technique avant de valider le profil. Ne transmettez ni code privé, ni identifiants, ni informations sur les clients de vos boutiques.

Après confirmation du périmètre par mail, vous recevrez deux brefs sur deux semaines, puis quelques questions sur leur utilité. Cet essai ne vous inscrit à aucune newsletter et ne commande aucune offre future.
